# TheGrowth — контекст проекта

Карточная игра с визуальными новеллами и ветвящимся сюжетом. Карты работают как фишки на поле.
Стилизация — карты Таро и гадальные карты. Product name в Unity — Thraumatrope. Делается автором
и друзьями вечерами, цель — релиз в Steam. Аудитория — девушки, далёкие от IT (моддинга нет).

Unity 6000.0 (C# 9). Платформы: PC (Steam), вероятно Android, iOS, Web (itch.io); macOS нет.
Плагины: DOTween, Odin Inspector (уходим), Naninovel (возможна замена своим решением).
Планируются: R3 + ObservableCollections, Spine.

Код прототипа: `Assets/_XandArt/TheGrowth/Code`. Контент: `Assets/_XandArt/TheGrowth`.

## Архитектура (кратко)

- **Жизненный цикл** — `GameFlow` единственный владелец переходов. Scopes Global → Session →
  Location. Новая игра и загрузка — один путь `CreateSession(SaveGame)`. Без статики.
- **Данные** — конфиги (SO, `int Id` на тип), runtime-состояние (C# классы в системах сессии),
  сейв (DTO с версией).
- **Карта** — `CardModel` → `CardInstance` → `CardSave`. Именованные переменные карты вместо `Charges`.
- **Зоны** — карта всегда ровно в одной зоне. Инвентарь — это колода, стаков нет.
- **Сохранения** — zip на слот, ручные без лимита + 3 автосейва по кругу. Посреди экспедиции —
  можно, в диалоге — нельзя.
- **Логика** — команды асинхронные, реакции карт срабатывают сразу (вложенно). Каждый скрипт
  завершается; сохраняться можно только без активных скриптов; игра строго пошаговая. Во время
  скриптов и анимаций карты недоступны, UI доступен. Цель — только перетаскиванием.
- **Скрипты** — только система команд (Lua не используем), на `[SerializeReference]` без Odin
  binary. Как дорабатывать команды — обсуждается в эпике E04.
- **Отображение** — 3D (хаб 2.5D), одна вьюха карты, минимальный UI. UI — MVVM на R3.
  Текущее управление камерой сохранить.
- **Код** — слои сборками, системы папками; Model не зависит от сцены. Приватные поля — `m_Field`.
