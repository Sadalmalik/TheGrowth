# TheGrowth — архитектура: диалоговая система

Часть детальной спецификации. Короткая версия — `CLAUDE.md` в корне. Требования дизайнера —
`.claude/docs/Диалоговая система.md` (с поправками ниже). Открытые вопросы — `.docs/Вопросы.md`.

## Решения (2026-10-17)

- **Своя диалоговая система вместо Naninovel.** Причины: Naninovel — самостоятельный движок,
  интеграция трудная, настройка его UI неочевидна, совместить с UI и визуалом игры крайне сложно.
- **Сценарии — тем же языком скриптов**: команды диалогов задаются `[Script(name, template)]`,
  как геймплейные.
- **Персонажи** — Spine или картинки.
- **Единый контейнер дизайнерских переменных** на игру — общий для скриптов карт и диалогов.
  Синхронизации переменных между системами нет. Отдельная задача — T052.
- **Описание и отображение разделены**: скрипт — команды; отображение — виджеты. Соответствия
  1:1 команда ↔ виджет нет: команда работает с одним или несколькими виджетами.
- `UIDialogManager`: методы для фона и персонажей + `Get<TWidget>()` для виджетов.
- Скрытое ветвление (игроку ничего не показывается) — обычный `if` по переменным.
- Изображения — библиотека в конфиге, команда ссылается на изображение по ID.
- Звук: мгновенные звуки + эмбиент по номерным каналам (1, 2, 3, ...).

## Отображение: три слоя

| Слой | Возможности |
|---|---|
| Фон | включить / переключить / выключить (мгновенно или через фейд); выключен — диалог идёт поверх игры; цвет, прозрачность; размер, масштаб; сдвиг (фон больше экрана — «перемещение по комнатам»); эффекты (тряска) |
| Персонажи | картинка или Spine; добавить / убрать (мгновенно, фейд, выезд из-за края); перемещение, масштаб; эмоция, анимация; говорящий по умолчанию чуть крупнее и светлее; расстановка по умолчанию: сторона экрана (Left/Right), персонажи одной стороны — в линию с заданным шагом |
| Виджеты (расширяемый) | реплика: персонаж, эмоция, текст с форматированием, посимвольный вывод; выбор: вопрос и варианты, вариант может быть неактивным или скрытым по условию; информационные: квестовые предметы, доверие персонажа и т.п. |

## Поправки к документу дизайнера

- «Загрузка изображений» не нужна: изображения берутся из библиотеки по ID.
- Бэклог (прокручиваемая история реплик) — часть диалоговой системы, но отдельное окно, не виджет.
- Журнал (квесты, известные факты, персонажи и места) — отдельный экран UI, не диалоговая система.
- Меню (выход, сохранение и загрузка, скрыть UI) — общеигровой UI.
- Переменные — отдельная система (T052).
