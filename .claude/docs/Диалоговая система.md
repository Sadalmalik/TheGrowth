# Диалоговая система

Описание функционала диалоговой системы, достаточной для запуска проекта. 

### Основная задача 

* Создать аналог диалоговой системы NaniNovel без лишних элементов  
* Создать редактор для диалоговой системы 

### Основные элементы системы

* Фон  
* Персонаж  
* Диалоговое окно  
* Портрет персонажа  
* Выборы  
* УИ элементы  
* Работа с переменными  
* Редактор


![][image1]

### Фон 

* Загрузка изображения  
* Включение/отключение фона  
* Смена изображения  
* Возможность использовать слои  
* Эффект перехода (затемнение)  
* Заложить анимацию фонового изображения (спайн или сиквенс)

### Персонаж

* Загрузка, включение\\отключение изображения персонажа  
* Изображение персонажа соответсвует реплике (персонаж, эмоция)  
* Интеграция Спайн для персонажей  
* Смена спрайта (эмоции или позы)  
  * С учетом говорящего и описания эмоции  
  * Переход с учетом спайн анимаций  
  * Мягкий переход со спрайта на спрайте если спрайт не анимирован  
* Эффекты изображений  
  * Трансформация (позиция Х\\Y, размер)  
  * Затемнение спрайта (для ночных фонов)  
  * Использование кривых для трансформаций (шейк эффект, “подпрыгивание” изображения)  
  * Авто-затемнение спрайта (не активный персонаж в реплике затемняется)

### Диалоговое окно

* Портрет персонажа  
  * Соответстовует реплике (какой персонаж говорит)  
  * Соответствовать выбранному полу Главного Героя при его репликах  
  * Пустой экран (если говорит нарратор)  
* Имя персонажа  
  * В зависимости от имени персонажа  
  * От выбраного имени игрока  
* Текст  
  * Плавная подача (побуквенно или построчно)  
  * Поинтер (череп)  
    * Появляется в конце реплики, сигнализирует что больше текста не будет  
  * Клик мышкой для мнгновенного вывода текста  
  * Клик мышкой для перехода на след. фразу (строку) после вывода текста  
  * Функция форматирования текста  
    * Обычный текст (базовые значения)  
    * Курсив  
    * Жирный  
    * Размер  
    * Цвет (?)  
* Кнопка пропуска (пропускает прочитанный текст, плюс кнопка “скип непрочитанного текста” в основных настройках)  
* Журнал (переход в УИ журнала игрока)  
* Бэклог (по нажитию кнопки или клавиши)  
* Желательно — бэклог текста в журнале игрока, кнопка перехода сразу в раздел бэклога журнала  
* Кнопки быстрой загрузка и сохранения

### Выборы

* Кнопки выбора в диалоге  
  * Функционал кнопки (смена спрайта или цвета на нажатие и тд)  
  * Настройка фраз на кнопках выбора в скрипте  
  * Возможность настройки расположения кнопок на экране  
* Переход в зависимости от выбора на нужный участок текста  
* Настройка в скрипте (когда, при каких условиях и куда переходим)  
* Стоп функция для вывода текста (следующая часть текста не пролистывается, пока игрок не сделает выбор)

### Интерфейс

* Выход в меню (крестик)  
* Вовзрат из меню  
* Скрыть УИ (клавиша, обычно на пробел)

### Сохранение

* Через главное меню  
* Быстрое сохранение и загрузка  
* Авто сохранение (задается в скрипте)  
* “Поп-Ап” надпись в углу экрана, сигнализирующая что автосохранение выполнено

### Звуки

* Задаются в скрипте  
  * Какой звук проиграть  
  * Громкость звука  
  * Длительность или разово  
* Возможность “лупа” для фоновой музыки и звуков  
* Стоп функция (по имени эффекта, стоп все)  
* Желательно \- фоновая музыка задается отдельно

### Переменные

* Возможность задавать переменные в редакторе  
  * Boolian  
  * Int  
  * String (?)  
* Проверка (булиан да\\нет)  
* Работа с переменными (сравнение, сложение)  
* Присвоение значений переменным в редакторе
