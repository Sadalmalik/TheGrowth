## Описание

Ядро сохранений (Core): `SaveGame` (meta + секции), zip на слот, интерфейс хранилища, слоты,
ротация автосейвов, `ISaveable`, миграции секций. Хранилище файлов — интеграция. Сессия
создаётся из сейва; `GameFlow` — запросы сохранения и загрузки, `CanSave`, автосейв при выходе.
Временные кнопки в меню. Спецификация — `.claude/architecture-data.md` («Сохранения»),
`.claude/architecture-flow.md`.

Не входит: хранилище для Web ([[T066 Хранилище сохранений для Web]]), автосейв по событиям
систем, которых ещё нет (ход и конец экспедиции, смена шага сюжета), облако Steam, настройки игрока.

## Критерии готовности

- [x] Сохранение в ручной слот из локации; загрузка из меню и из локации возвращает в ту же локацию.
- [x] 3 автосейва по кругу: перезаписывается самый старый.
- [x] Ошибка во время записи не портит предыдущий файл слота.
- [x] Список слотов строится по `meta.json`, без чтения секций.
- [x] Цепочка миграций при чтении секции; тест на фикстуре старого сейва.
- [x] Автосейв при выходе в меню и из игры; выход из приложения ждёт конца записи.
- [x] Битый слот не ломает текущую игру.
- [x] Тесты EditMode и PlayMode проходят.
