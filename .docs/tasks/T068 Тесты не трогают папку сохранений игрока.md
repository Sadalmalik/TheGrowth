## Описание

PlayMode-тесты пишут в настоящую папку сохранений (`persistentDataPath/saves`): перед тестом
убирают её в `saves.test-backup`, после — возвращают. 2026-10-20 в прогоне T067 перенос не удался,
`TearDown` удалил папку — сохранения автора потеряны. Сейчас `TestSavesFolder` папку при неудаче
не удаляет, но тесты по-прежнему трогают данные игрока.

Сделать: папка хранилища задаётся при сборке глобальной области; PlayMode-тесты подставляют
отдельную временную папку и не трогают `saves`. Убрать перенос папки.

## Критерии готовности

- [x] PlayMode-тесты пишут сохранения во временную папку системы, своя на каждый тест.
- [x] Перенос и удаление папки игрока убраны.
- [x] Тест сохранения проверяет, что папка игрока не изменилась.
- [x] Тесты EditMode и PlayMode проходят.
