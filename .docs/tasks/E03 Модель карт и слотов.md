## Описание

Модель игры без сцены: реестр контента и ID, карты, слоты.
Подробности — [[Карты и слоты]], [[Логика и отображение]]; спецификация — `.claude/architecture-data.md`,
`.claude/architecture-logic.md`.

## Объём (переформулировано 2026-10-23)

Модель экспедиции без сцены, по шагам:

1. Сущности и конфиг `EntityModel`: вид (Card / Modifier / Mechanic), пресеты, обязательные
   компоненты, компоненты Settings → Behaviour → Save, теги из реестра, переменные карты,
   `[ModelKind]`, реестр экземпляров, сейв — [[T073 Сущности и слоты]].
2. Система слотов: атомарное перемещение, правила, события, служебные слоты экспедиции и слоты
   поля из графа, сейв — [[T073 Сущности и слоты]].
3. Скрипты карт: файл `.script`, шесть хуков, свойства `->` (`AllowedMoves`, `SpawnSlot`),
   базовые эвалуаторы и команды карт и слотов — [[T074 Скрипты карт]].
4. ГСЧ сессии — вместе с шагом 5 (2026-11-04).
5. Колода и начальная раскладка — [[T072 Начальная раскладка поля]].
6. Персонаж, карта героя, карты способностей.
7. Ход экспедиции в модели: ход героя, ответ монстров, конец экспедиции.
8. Объекты механики на связях — после базовой экспедиции.

## Критерии готовности

- [ ] Headless-тест: старт экспедиции, ход игрока, ход монстров, конец экспедиции — проверка слотов.
- [ ] Карта не может оказаться в двух слотах (тест на инвариант).
