## Описание

Шаги 1 и 2 эпика E03: сущности с компонентами, единый конфиг `EntityModel` с видами и пресетами,
реестр экземпляров, система слотов, сейв. Спецификация — `.claude/architecture-data.md`
(«Сущности: композиция», «Модель карты», «Слоты», «Поле — граф слотов», «Системы сессии»).

## Критерии готовности

- [x] `EntityModel` с видом (Card / Modifier / Mechanic), пресеты в меню создания, обязательные компоненты вида нельзя удалить, валидатор дописывает недостающие.
- [x] Компоненты Settings → Behaviour → Save со стабильным ключом; инспектор списка компонентов без Odin.
- [x] Теги из реестра; переменные карты (список из объявлений + значения по умолчанию на модели).
- [x] `[ModelKind]` — инспектор, валидатор, парсер скриптов.
- [x] Реестр экземпляров (счётчик `InstanceId`), модификаторы на сущности-владельце.
- [x] Система слотов: атомарное перемещение, правила, события; служебные слоты экспедиции и слоты поля из графа.
- [x] Сейв и загрузка сущностей и слотов; карта не может оказаться в двух слотах (тест).
- [x] Тесты EditMode проходят (кроме `GraphValidationTests.TestLocation_HasGraphNextToScene_WithSpawnAndExit`: в графе тестовой
  локации 8 слотов `PlayerSpawn`, тест ждёт 1 — падает и без этой задачи).

## Доработки 2026-11-04

- Покрытия переименованы в модификаторы: `EntityKind.Modifier`, `Entity.Modifiers`, `EntityRegistry.AddModifier`, ключ сейва
  `modifiers`, пресет `Create/[Game]/Entity/Modifier`.
- Теги — CamelCase (`TagCatalog.IsValidName`); `exit` удалён, остался `Exit`.
- `GraphValidationTests`: проверяется только структура графа тестовой локации (не число `PlayerSpawn`).
