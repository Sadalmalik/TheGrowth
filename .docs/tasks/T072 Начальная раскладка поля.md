## Описание

Раскладка карт на поле при старте экспедиции. Решения — `.claude/architecture-data.md`, «Колода и
начальная раскладка». Нужны колода, экземпляры карт и система слотов (E03), граф поля (T069).
Закрывает [[T015 Колода - карты, которые не выпадают при первой раскладке]],
[[T022 Баг - пустые слоты при раздаче]], [[T026 Баг - монстр спавнится на карте выхода]].

## Критерии готовности

- [ ] Колода экспедиции — конфиг локации: «модель + количество», галка «не раскладывать».
- [ ] Карты с `SpawnSlot` (набор слотов) — первыми, остальные — случайно, герой — последним на `PlayerSpawn`.
- [ ] Карт меньше слотов — слоты пустые; больше — остаток в колоде.
- [ ] `OnPlacedFirstTime` — отдельным циклом после раздачи, в порядке раздачи, герой последним.
- [ ] ГСЧ сессии; одинаковое состояние ГСЧ — одинаковая раскладка (тест).
- [ ] Валидатор: нет `PlayerSpawn`; `SpawnSlot` без свободного слота — предупреждение.
