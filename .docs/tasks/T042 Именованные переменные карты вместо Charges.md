## Описание

Вместо отдельного компонента `Charges` — у карты список произвольных именованных переменных
(имя → значение), чтобы дизайнеры могли сами добавлять нужные (заряды, счётчики и т.п.).
Команды и кондишены работают с переменной по имени.
