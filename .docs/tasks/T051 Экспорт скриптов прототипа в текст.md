## Описание

Выгрузить все скрипты прототипа (команды, кондишены, эвалуаторы в конфигах карт, шагах сюжета,
квестах, кнопках сцен и префабов) из данных Odin в текстовый формат. Формат может отличаться от
будущего языка — переписать текст потом на порядки проще, чем доставать данные из Odin.

## Критерии готовности

- [x] Редакторская команда выгрузки в сборке прототипа.
- [x] Выгружены все ассеты, префабы и сцены со скриптами; файл на источник.
- [x] Ничего не потеряно: в выгрузке видны все команды с параметрами.
