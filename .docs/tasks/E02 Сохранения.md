## Описание

Сохранения на DTO: слоты, автосейвы, миграции. Подробности — [[Данные и сохранения]];
спецификация — `.claude/architecture-data.md`.

## Объём

- `SaveService`: zip на слот, `meta.json`, секции, превью, атомарная запись.
- `ISaveable`, `SaveableSystem<TSave>`, `ISessionReady`, порядок чтения.
- Ручные слоты без лимита, 3 автосейва по кругу.
- Автосейв по событиям при `GameFlow.CanSave`.
- Версии секций и цепочка миграций, тест-фикстуры.

## Критерии готовности

- [ ] Сохранение посреди экспедиции и загрузка восстанавливают поле, руку, ходы, рандом.
- [ ] Повреждение во время записи не портит предыдущий файл слота.
- [ ] Список слотов строится без чтения секций.
