## Описание

База системы команд в Core на UniTask. Спецификация — `.claude/architecture-scripting.md`,
разделы «База команд» и «Исполнитель и управляющие команды». Парсер и принтер — отдельной задачей.

## Критерии готовности

- [x] Пакет UniTask подключён.
- [x] `ScriptAttribute`, `Command`, `InstantCommand`, `ControlCommand` / `ControlStep`, `Condition`, `Evaluator<T>`.
- [x] `ScriptContext`, модель файла скрипта (файл, секции, блоки).
- [x] `ScriptRunner`: стек кадров, `goto` / `call` / `return`, вложенные запуски, `Background`,
      учёт запусков, ожидание игрока, ошибки с позицией, защита от зацикливания, снимок позиции.
- [x] Базовые команды: `if`, `goto`, `call`, `return`, `parallel`, `background`, `log`.
- [x] EditMode-тесты на всё перечисленное проходят.
