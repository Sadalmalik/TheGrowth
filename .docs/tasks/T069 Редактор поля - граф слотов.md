## Описание

Данные графа поля и редактор в Scene View по решениям [[T057 Слоты без сетки - эвалуаторы и связи]].
Спецификация — `.claude/architecture-data.md`, «Поле — граф слотов», «Редактор поля». Минимальный
общий реестр тегов. Без объектов механики и без использования графа в игре (E03).

## Критерии готовности

- [x] Конфиг графа рядом со сценой: слоты (ID, 3D-позиция, теги), связи (ID, два слота), сетки-группы.
- [x] Компонент `Graph` на сцене ссылается на конфиг и рисует гизмо; `LocationModel` ссылается на тот же конфиг.
- [x] Панель инструментов в Scene View: Выбор, Single, Grid (с панелью настроек), Связи, автоконнект, минимальный радиус; Esc сбрасывает.
- [x] Инспектор `Graph`: параметры выбранного элемента (теги из реестра; у сетки — удалить целиком).
- [x] Отмена (Ctrl+Z) всех правок.
- [x] Реестр тегов: конфиг, проверка дублей и формата.
- [x] Граф в тестовой локации.
- [x] Тесты EditMode проходят.
