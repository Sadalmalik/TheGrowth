## Описание

Режим «раскрашивания тегами» в редакторе поля, чтобы не назначать тег каждой клетке по
отдельности. Спецификация — `.claude/architecture-data.md`, «Редактор поля».

## Критерии готовности

- [x] Режим **Tags** после **Links**: ползунок размера кисти, текущий тег из реестра.
- [x] Круг кисти под мышью.
- [x] ЛКМ — тег добавляется слотам в кисти; Shift+ЛКМ — убирается.
- [x] Одно протягивание — один шаг Ctrl+Z; Esc сбрасывает.
- [x] Тесты EditMode проходят.
