## Описание

Фундамент, часть 2: `GameFlow` со сценами, стартовая сцена `Main`, `LocationRoot` и
`LocationScope`, `ILifetime`, обратный порядок `Dispose` в контейнере, базовый запуск из сцены
локации в редакторе (без пресетов). Сохранение и загрузка — в E02. Спецификация —
`.claude/architecture-flow.md`.

## Критерии готовности

- [x] `Container`: `Dispose` в порядке, обратном регистрации.
- [x] `ILifetime` в каждой области; `ScriptRunner` берёт токен из него.
- [x] `GameFlow`: очередь запросов, состояния, блокировка ввода, экран загрузки (интерфейс).
- [x] Запросы: в меню, новая игра, вход в локацию, выход в меню, выход из игры.
- [x] `LocationRoot` + `ILocationBehaviour`: инжект и инициализация в явном порядке, включая неактивные.
- [x] Сцена `Main` с точкой входа и временным меню; тестовая сцена локации.
- [x] Play из сцены локации в редакторе: старт с `Main`, новая сессия, вход в эту локацию.
- [x] Тесты EditMode и PlayMode проходят.
