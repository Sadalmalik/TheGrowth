## Описание

Хвосты после парсера и принтера (T056).

## Критерии готовности

- [ ] Свойства-выражения в файле карты: строка с нулевым отступом `Имя -> [выражение]`.
- [ ] Проверка существования секций по ссылкам `goto` / `call` / `dialog`.
- [ ] Переимпорт скриптов при изменении шаблонов (зависимость импортёра).
- [ ] Проверка на IL2CPP и Web: урезание кода (`[Preserve]` / link.xml для классов с `[Script]`),
      `Constant<T>` через `MakeGenericType` от value-типов.
- [ ] Валидатор: ID файлов скриптов — идентификаторы; ID персонажей не совпадают с ключевыми словами.
- [ ] Реестр языка: параметр-конфиг команды должен быть наследником `ContentAsset`.
- [ ] Печать → разбор → печать для текста до конца строки с переводом строки или окончанием ` #xxxxxx`.
