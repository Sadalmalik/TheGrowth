## Описание

Первая часть E08: база MVVM (Architecture), корень UI со слоями, наблюдатели по областям жизни,
всплывающие окна, навигация геймпадом, первые экраны вместо временного меню. Подключение R3,
ObservableCollections и Input System (режим `Both`). Спецификация —
`.claude/architecture-presentation.md` («UI (MVVM)», «Решено 2026-10-20»).

Не входит: HUD экспедиции, подсказка карты, уведомления, настройки, локализация (T039).

## Критерии готовности

- [x] R3, ObservableCollections, Input System подключены; Active Input Handling — `Both`.
- [x] `View<T>`, `ViewModel`, `AddTo`, `WidgetList` с пулом — в Architecture.
- [x] Корневая VM со свойством на слой; фабрика «тип VM → префаб» с пулом; анимации окон на DOTween.
- [x] Наблюдатели глобальной области и сессии; сессионный уничтожается с сессией.
- [x] Всплывающие окна; ошибка загрузки показывается понятным текстом.
- [x] Модальные окна блокируют игровой ввод.
- [x] Навигация геймпадом по всем экранам задачи.
- [x] Экраны: главное меню, сохранение и загрузка, пауза, экран загрузки; `TemporaryMenu` удалён.
- [x] Тесты EditMode и PlayMode проходят.
