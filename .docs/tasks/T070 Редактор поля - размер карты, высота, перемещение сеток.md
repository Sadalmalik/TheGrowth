## Критерии готовности

- [x] Глобальная настройка размера карты (1,5 × 2), один конфиг на проект.
- [x] Слоты в гизмо — прямоугольники по размеру карты.
- [x] Шаг сетки по X и Z — в размерах карты; автоконнект и минимальный радиус — тоже.
- [x] Высота клеток сетки — рейкаст вниз с высоты начальной точки + смещение.
- [x] Сетку можно двигать и вращать целиком; прямоугольники не поворачиваются; Ctrl+Z.
- [x] Граф тестовой локации пересобран.
- [x] Тесты EditMode проходят.
