## Описание

Протянуть в код процедурные анимации из GeekyHouse (модуль `ProceduralAnim`, коммит `82ed47f`) и настроить ими анимации карт и слотов. Где лежат конфиги —
`.claude/architecture-presentation.md`, раздел «Конфиги анимаций».

## Объём

- Перенести `Assets/_XandArt/Modules/ProceduralAnim` и `Modules/Utils` в `Code/Architecture/`.
- Убрать enum `AnimationSlots` (ключи мержа GeekyHouse) и зависимость от Odin.
- `CardAnimationSet` (Presentation) — ссылки на профили именованными полями.
- Анимации карт:
  - [ ] появление / исчезновение (масштаб из / в 0);
  - [ ] перемещение в слот (перетаскивание, телепорт, раздача из колоды);
  - [ ] баунс при приземлении;
  - [ ] зум при осмотре;
  - [ ] «плавание» карт не на поверхности (смена угла, параллакс внутри карты);
  - [ ] перемещение в колоду.
- Анимации слотов:
  - [ ] сортировка колоды;
  - [ ] растягивание колоды вдоль кривой (просмотр инвентаря).
- Реализация `ICardAnimator` (Presentation) на профилях.

## Критерии готовности

- [ ] Все анимации настраиваются ассетами профилей без правки кода.
