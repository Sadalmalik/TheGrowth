## Описание

Единая система дизайнерских переменных — общая для скриптов карт и диалогов. Решения —
`.claude/architecture-data.md`, раздел «Переменные». Связано с
[[T042 Именованные переменные карты вместо Charges]].

## Критерии готовности

- [ ] Конфиги объявления переменных (имя, тип, значение по умолчанию, описание).
- [ ] Области: игра (секция сейва), карта, профиль (вне слотов).
- [ ] Ссылки `$имя` и `[карта].имя` в языке, проверка существования и типа при разборе.
- [ ] Событие изменения переменной в `EventBus`.
