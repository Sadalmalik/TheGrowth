## Описание

Единая система дизайнерских переменных — общая для скриптов карт и диалогов. Решения —
`.claude/architecture-data.md`, раздел «Переменные». Связано с
[[T042 Именованные переменные карты вместо Charges]].

Минимальный набор команд и узлов, без которого переменные не используются: `set`, `add`,
сравнения, `and` / `or` / `not`, `+` / `-`. Переменные карты — механизм владельца переменных и
синтаксис `[узел].имя`; сам экземпляр карты и список переменных на модели карты — E03 (T042).

## Критерии готовности

- [x] Конфиги объявления переменных (имя, тип, значение по умолчанию, описание).
- [x] Области: игра (секция сейва), карта, профиль (вне слотов).
- [x] Ссылки `$имя` и `[карта].имя` в языке, проверка существования и типа при разборе.
- [x] Событие изменения переменной в `EventBus`.
