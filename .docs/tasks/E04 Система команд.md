## Описание

Перевод скриптов с Odin на свой текстовый язык и доработка системы команд.
Подробности — [[Скрипты]].

## Объём

- Язык скриптов: шаблоны команд в атрибутах, принтер, парсер, импортёр, проверка типов.
- Файл скриптов на карту, общеигровые файлы с хуками, ссылки объектов сцены на хуки.
- Миграция с Odin: выгрузка → текст на новом языке; прочие конфиги — на Unity-сериализацию.
- Команды `Parallel` и `Background` (решено).
- Инспектор скриптов rich-текстом, как редактор триггеров Warcraft 3 (решено,
  см. `.claude/architecture-scripting.md`).
- Каталог команд для ИИ — скилл, генерируется из атрибутов.

## Критерии готовности

- [ ] Ни одного файла с `SerializedFormat: 0`.
- [ ] Деревья скриптов после разбора текста совпадают с выгрузкой из Odin.
- [ ] Переименование класса команды не ломает скрипты.
