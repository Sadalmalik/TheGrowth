## Описание

Фундамент, часть 1: исправление `Container` (T055), `Session` / `SessionBuilder` и области жизни
с токенами отмены, `ContentRegistry` со строковыми ID конфигов, резолвер ID для языка скриптов.
Без сцен: `GameFlow` со сценами и `Main` — отдельной задачей. Связь с сохранениями — в E02.

## Критерии готовности

- [x] `Container`: `Init`, `Dispose` и инжект — один раз на экземпляр (T055).
- [x] Области жизни: контейнер + токен отмены, вложенные области отменяются вместе с родителем.
- [x] `Session` и `SessionBuilder` (Model), headless-создание сессии в тестах.
- [x] `ContentRegistry`: строковые ID, поиск по типу и ID, валидатор, сборка реестра в редакторе.
- [x] `IScriptContentResolver` на реестре контента, импортёр использует его вместо заглушки.
- [x] Тесты EditMode проходят (старые + новые).
