## Описание

Шаг 6 эпика E03: персонаж, карта героя, карты способностей, ёмкость слотов; фигуры поля для
способностей. Спецификация — `.claude/architecture-data.md` («Герой и способности, шаг 6 E03», «Ёмкость
слотов»), `.claude/architecture-scripting.md` («Фигуры»).

Решено 2026-11-04:
- Персонаж пока минимальный: ID, имя. Портреты, Spine, эмоции — с диалогами (E12).
- Способность ссылается на персонажа; без владельца — способность игрока.
- Розыгрыш способности — шаг 7; заканчивает ли он ход — решает скрипт способности.
- Ёмкость слотов настраивается: инвентарь хаба — без лимита, рука экспедиции — 3 карты; карта героя для
  старта обязательна.
- Фигуры в метрах: круг; квадрат с поворотом и масштабом (ромб — квадрат 45° со скейлом 1,5); линия из
  центра под углом в одну или обе стороны. Крест — `[line 45 5m] or [line -45 5m]`.

## Критерии готовности

- [x] Конфиг персонажа; компонент карты героя (ссылка на персонажа); компонент способности (владелец).
- [x] Ёмкость служебных слотов — из конфига; рука экспедиции — 3.
- [x] Раскладка кладёт способности в руку; чужая способность или переполнение руки — ошибка до изменений.
- [x] Фигуры: круг, квадрат (поворот, масштаб), линия (одна или обе стороны), операции над фигурами.
- [x] Примеры: персонажи и карты героев Lucia, Alfredo, Stefan; способности Vision, Revolver, Teleport,
  Confuse, Talisman (части хода — шаг 7, комментариями).
- [x] Тесты EditMode и PlayMode проходят (2026-11-04: EditMode — 849 тестов, 848 пройдено, 1 пропущен: `[Ignore]` у
  теста прототипа; PlayMode 4 из 4).
