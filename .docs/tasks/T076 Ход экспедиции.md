## Описание

Шаг 7 эпика E03, часть 1: ход экспедиции в модели, без сцены и `GameFlow`. Спецификация —
`.claude/architecture-data.md` («Ход экспедиции»), `.claude/architecture-scripting.md` («Узлы хода экспедиции»).
Старт и конец через `GameFlow` — T077.

Решено 2026-11-04:
- Действие игрока: героя на поле или карту из руки (лицом вверх, `AllowedMoves` не пуст) — на слот из
  `AllowedMoves`, иначе отмена без событий. Действие с концом хода — одна активность для сохранения.
- Конец хода решает скрипт (`end turn`); обработка после действия: `OnStep` верхних карт клеток поля, затем
  счётчик ходов. Пропуск хода — конец хода без действия.
- Счётчик ходов встроенный; ноль обрабатывает скрипт. Номер хода растёт сам.
- `end expedition with victory/defeat`: текущий скрипт дорабатывает, остаток хода пропускается.
- Итоги: победа — рюкзак в инвентарь; поражение — рюкзак теряется; герой и способности возвращаются в
  инвентарь всегда.
- `move [Card] to [Slot] without hooks` — перемещение без хуков размещения.
