Логику карт, сюжета и реакций на кнопки настраивают все — дизайнеры и программист — через
**систему команд**. Lua и C# для логики карт не используем.

- **Команда** — действие: переместить карту, перевернуть, раздать, запустить диалог.
- **Кондишен** — проверка: карта в группе, значение переменной больше N.
- **Эвалуатор** — вычисляет значение: активная карта, ближайший слот, число карт.

Команды можно вставить куда угодно: в реакцию карты, в шаг сюжета, на кнопку.

## Решено

- **Скрипты хранятся текстом на своём языке.** Язык — это то, что показывает инспектор:

```
OnPlaced:
    if [charge > 1] and [[distance between [hero] and [target]] < 5]
        log "We are near target"
        AddBuff poison to [hero]
    else
        log "We are too far"
```

- **Файл на карту** — рядом с ассетом карты, реакции карты (хуки) — секциями.
- **Общеигровые скрипты** (кнопки UI, триггеры) — отдельный файл с именованными хуками; объект
  сцены выбирает хук по имени.
- Имена хуков — без пробелов: `OnPlaced`, `OnStep`.
- **Инспектор** рисует тот же текст с управлением: `[...]` — клик открывает редактирование,
  `=` — перетаскивание строки, `[+]` / `[-]` — добавить / удалить команду. В файле этих элементов
  нет.
- Ошибки в файле видны сразу при импорте, с номером строки.
- ИИ пишет такие файлы по описанию дизайнера; каталог команд генерируется из кода.
- **Параллельность:** `Parallel` — запустить вложенные команды одновременно и дождаться всех;
  `Background` — запустить и не ждать.

## Как команда задаёт свой вид в тексте

Имя и синтаксис команды задаются атрибутом на классе:

```csharp
[Script("if", "if [Condition] {OnTrue} else {OnFalse}")]
```

- `[Поле]` — параметр, в тексте кликабелен.
- `{Поле}` — блок вложенных команд: в тексте — перенос строки и отступ.
- Текст между блоками — строки-продолжения (`else`). Продолжение без параметров с пустым блоком не
  показывается: `if` без `else` — просто `if` с блоком.
- Имя (`"if"`) — для списка команд в инспекторе и каталога для ИИ. Имя класса ни на что не влияет.

## Переход с Odin

1. Выгрузить все скрипты из конфигов и сцен (пока Odin ещё работает).
2. Записать их текстом на новом языке; скрипты кнопок — хуками в общеигровой файл.
3. Остальные конфиги перевести на стандартную сериализацию Unity.
4. Проверить, что после разбора файлов ничего не потерялось.
5. Удалить Odin.
