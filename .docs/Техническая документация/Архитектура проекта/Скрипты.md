Логику карт, сюжета и реакций на кнопки настраивают все — дизайнеры и программист — через
**систему команд**. Lua и C# для логики карт не используем.

- **Команда** — действие: переместить карту, перевернуть, раздать, запустить диалог.
- **Кондишен** — проверка: карта в группе, значение переменной больше N.
- **Эвалуатор** — вычисляет значение: активная карта, ближайший слот, число карт.

Команды можно вставить куда угодно: в реакцию карты, в шаг сюжета, на кнопку.

## Решено

- Уходим с бинарного формата Odin на стандартную сериализацию Unity (`[SerializeReference]`).
  Конфиги станут читаемым текстом, переименование класса перестанет стирать настройки карт.

## Обсуждается

Как дорабатывать систему команд — в эпике [[E04 Система команд]].

## Переход с Odin

1. Выгрузить все скрипты из конфигов и сцен в JSON (пока Odin ещё работает).
2. Перевести классы на стандартную сериализацию Unity. Odin пока рисует инспектор — для
   дизайнеров ничего не меняется.
3. Загрузить данные из JSON обратно, сохранить ассеты и сцены.
4. Сравнить новую выгрузку со старой — ничего не должно потеряться.
5. Позже — свои инспекторы вместо Odin, удаление Odin.
