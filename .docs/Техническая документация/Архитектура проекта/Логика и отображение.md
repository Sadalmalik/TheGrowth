## Решено

- **Команды асинхронные.** Продолжительное действие (перемещение, переворот, диалог)
  ожидается — следующая команда выполняется после его завершения. Раньше для этого был
  `AfterCommands`.
- **Реакции карт срабатывают сразу.** Если с картой что-то сделали — она сразу реагирует
  (вложенные вызовы команд).
- **Каждый скрипт завершается.** Вечных циклов в системе команд нет.
- **Сохраняться можно, только когда нет ни одного активного скрипта.** Игра строго пошаговая,
  поэтому такие моменты гарантированно есть.
- **Цель** выбирается только перетаскиванием карты.
- Пока выполняются скрипты и анимации, с картами взаимодействовать нельзя, с UI — можно.
