[[Главная]]

Локальный трекер задач команды. Задача — отдельный документ в папке `tasks/` со свойствами
(frontmatter). Таблицы строит база [[Task Tracker.base|Задачи]] (встроенный плагин Obsidian Bases).

![[Task Tracker.base]]

Вопросы задачами не заводятся — они живут в [[Вопросы]].

## Как завести задачу

1. Создать документ в `tasks/` из шаблона `_templates/Задача.md` (команда «Templates: Insert
   template» или кнопка шаблонов).
2. Имя файла: `T<номер> <Короткое название>` — номер следующий за последним. Эпики:
   `E<номер> <Название>`.
3. Заполнить свойства и описание.

## Свойства

| Свойство | Значения | Смысл |
|---|---|---|
| `type` | `task` | по нему база находит задачи — не менять |
| `status` | `backlog`, `todo`, `in-progress`, `review`, `verify`, `done`, `dropped` | см. ниже |
| `kind` | `epic`, `feature`, `bug`, `design`, `tech` | вид задачи |
| `area` | `architecture`, `scripting`, `cards`, `expedition`, `hub`, `craft`, `story`, `dialogue`, `ui`, `camera`, `audio`, `vfx`, `tools`, `content` | область игры |
| `priority` | `high`, `medium`, `low` | приоритет |
| `assignee` | имя | кто делает |
| `epic` | ссылка `[[E01 ...]]` | к какому эпику относится задача |
| `depends` | ссылка `[[E01 ...]]` | для эпиков: какой эпик нужно сделать раньше |
| `source` | текст | откуда задача (`notes.txt`, обсуждение, плейтест) |
| `created`, `updated` | дата | создана / последнее изменение |

## Статусы

| Статус | Значение |
|---|---|
| `backlog` | записано, не запланировано |
| `todo` | запланировано, можно брать |
| `in-progress` | в работе |
| `review` | сделано, ждёт проверки |
| `verify` | неизвестно, актуально ли: проверить в текущей сборке и перевести в `todo` / `done` / `dropped` |
| `done` | сделано |
| `dropped` | не делаем или устарело |

## Перенос из notes.txt

Незакрытые задачи из `notes.txt` перенесены 2026-10-10 с `source: notes.txt`, неактуальные
удалены 2026-10-11.
